# Student Management System (OOPS – Python)

This project is a simple **Student Management System** developed using **Object-Oriented Programming (OOPS)** concepts. 
It demonstrates inheritance, method overriding, and encapsulation with an interactive user interface built using streamlit

---

##  Project Objective
To manage student details and automatically calculate grades using OOPS principles.

---

## OOPS Concepts Used
- Classes & Objects  
- Inheritance  
- Method Overriding  
- Encapsulation
